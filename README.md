## 📌 Sobre o projeto

Programa em Python desenvolvido durante um programa de iniciação em
tecnologia. A calculadora ajuda o usuário a estimar quanto um aparelho
elétrico consome de energia por mês, e quanto isso custa em reais, a
partir de dados simples de uso informados por ele mesmo.
